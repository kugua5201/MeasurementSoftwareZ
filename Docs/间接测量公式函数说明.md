# 间接测量公式函数说明

本文档说明当前间接测量公式脚本支持的写法、运算符、常量、函数和变量命名规则。
## 编辑器说明

## 间接测量触发模式

当前间接测量支持以下三种触发模式：

1. **事件触发**
   - 绑定的点位值事件一收到，就计算并存储一次
   - 不区分公式变量值是否真的变化

2. **任意变化触发**
   - 相对上一次已计算时的变量快照，只要任意一个变量值发生变化，就计算并存储一次

3. **全部变化触发**（默认）
   - 相对上一次已计算时的变量快照，只有当所有变量值都发生变化后，才计算并存储一次
   - 例如上次计算快照为 `X1=145、X2=156`，后续只有当快照变成类似 `X1=146、X2=147` 这种两个变量都变了，才会再次触发计算
   - 这样可以避免间接测量在同一轮点位更新过程中，比直接测量多追加历史数据

## 1. 脚本写法

```text
A = (X1 + X2) / 2
B = abs(X3 - X4)
RESULT = round((A + B) / 2, 3)
```

规则：

- 一行写一个表达式
- 中间变量写法：`变量名 = 表达式`
- **最后一行必须写 `RESULT = 表达式`**
- 检查脚本和运行脚本时，会按行从上到下顺序执行
- 支持空行
- 支持注释行：
  - `# 注释内容`
  - `// 注释内容`
## 2. 基本规则


- 结果值必须赋值给 `RESULT` 变量，且只能在最后一行赋值，且不区分大小写
- 公式区分大小写不敏感，函数名可写成 `sin`、`SIN`、`Sin`。
- 支持空格，解析时会自动忽略。
- 变量名由用户在“数据源”表格中配置，例如 `X1`、`A`、`DIA_1`。
- 变量名必须：
  - 以字母或下划线 `_` 开头
  - 后续只能包含字母、数字、下划线 `_`

示例：

- 合法：`X1`、`A`、`_Temp`、`DIA_1`
- 非法：`1X`、`A-B`、`直径`

## 3. 支持的运算/结构符号（共 17 个）

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `+` | 加法 | `X1 + X2` |
| `-` | 减法 | `X1 - X2` |
| `*` | 乘法 | `X1 * 2` |
| `/` | 除法 | `X1 / X2` |
| `%` | 取模 | `X1 % 2` |
| `^` | 幂运算 | `X1 ^ 2` |
| `|` | 按位或（整数位运算） | `X1 | X2` |
| `||` | 逻辑或（非 0 视为 true） | `X1 || X2` |
| `&` | 按位与（整数位运算） | `X1 & X2` |
| `&&` | 逻辑与（非 0 视为 true） | `X1 && X2` |
| `<<` | 左移位（整数位运算） | `X1 << 2` |
| `>>` | 右移位（整数位运算） | `X1 >> 1` |
| `~` | 按位取反（整数位运算） | `~X1` |
| `!` | 逻辑非（非 0 视为 true） | `!X1` |
| `(` | 左括号 | `(X1 + X2) / 2` |
| `)` | 右括号 | `(X1 + X2) / 2` |
| `,` | 参数分隔符 | `max(X1, X2, X3)` |

> 说明：
>
> - `^` 在当前公式里表示“幂运算”，**不是** C# 里的按位异或。
> - 如果需要“按位异或”，请使用 `xor(a, b)` 函数。
> - `|`、`&`、`<<`、`>>`、`~` 会先将参与运算的值截断为整数再做位运算。
> - `||`、`&&`、`!` 会把非 0 视为 `true`，返回结果为 `1` 或 `0`。

## 6. 常见公式/脚本示例

### 5.1 两个点位求平均

```text
(X1 + X2) / 2
```

### 6.2 多行组合脚本示例

```text
A = (X1 + X2) / 2
B = max(X3, X4, X5) - min(X3, X4, X5)
RESULT = round(A + B, 3)
```

### 6.3 差值绝对值

```text
abs(X1 - X2)
```

### 6.4 平方根与幂运算

```text
sqrt(pow(X1, 2) + pow(X2, 2))
```

### 6.5 三角函数示例

```text
sin(deg(X1))
```

### 6.6 多变量最大最小差

```text
max(X1, X2, X3) - min(X1, X2, X3)
```

### 6.7 保留 3 位小数

```text
round((X1 + X2) / 2, 3)
```

```text
(X1 | X2) << 1
```

### 6.9 按位异或示例

```text

```

### 6.10 按位取反与逻辑非示例

```text
~X1
```

```text
!X1
```

## 7. 脚本检查建议

建议在保存前先点击“检查脚本”按钮：

- 检查变量名是否重复
- 检查变量名格式是否正确
- 检查函数名和参数个数是否正确
- 检查表达式语法是否正确
